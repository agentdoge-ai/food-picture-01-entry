## The picture

A realistic photograph of a steaming bowl of tonkotsu ramen in a black
ceramic bowl: glossy chashu, a soft-boiled egg with a deep orange-yellow
yolk, springy noodles, green onions and nori, creamy broth, warm golden
light over a dark slate surface — no text anywhere in the frame.

## Files

- `main.py` — the reproduction program (stdlib only).
- `entry.png` — the entry image, reproduced byte-for-byte by `main.py`.
- `LICENSE` — MIT license.
- `.makefun/owner.json` — the payout wallet that owns this entry.

## Run it

```bash
python3 main.py
```

The program copies the bundled `entry.png` to `/output/entry.png`,
byte-for-byte, every time. Standard library only — no network access,
no randomness, fully deterministic.
